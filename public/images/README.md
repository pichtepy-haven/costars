# Images

Put event photos here and reference them in `src/data.js` with a path that
starts with `/images/…`. For example, the file `public/images/acts/khmer-dance.webp`
is written as `'/images/acts/khmer-dance.webp'`.

| Folder       | What goes in it                                   | Suggested size            |
| ------------ | ------------------------------------------------- | ------------------------- |
| `acts/`      | One photo per act (hero) plus gallery photos      | 1600 px wide, landscape   |
| `performers/`| Performer portraits                               | 800 px, square or 4:5     |
| `sponsors/`  | Sponsor logos                                     | SVG or PNG, ~400 px wide  |
| `charity/`   | Beneficiary school photos (from the proposal)     | already optimised         |
| `brand/`     | Musicians silhouette used in the stage artwork    | do not rename             |

Tips
- Prefer **.webp** (or .jpg) and keep each photo under ~300 KB. https://squoosh.app
  converts and compresses photos in the browser.
- Use lowercase file names with dashes and no spaces: `song-hui-chan.webp`.
- Only use photos you have permission to publish, especially photos of children.
